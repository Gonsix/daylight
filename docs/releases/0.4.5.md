Daylight brings a daily timeline, Kanban tasks, projects, and work-session tracking into one Obsidian view.
Everything is saved as ordinary Markdown notes in your vault.

### Changes in 0.4.5

- The bundled event, task, and project templates now contain only frontmatter. Their bodies are empty.
- New notes have empty bodies when no memo or goal is entered.
- Notes and Goal sections are added only when their corresponding input is provided. Custom template body content remains supported.
- Version 0.4.4 is intentionally skipped.

### Install or update

Requires **Obsidian 1.8.7+**. Download `main.js`, `manifest.json`, and `styles.css` into your configured Obsidian folder's `plugins/daylight/` directory. Keep `data.json` when updating, then reload Daylight.

Existing vault templates are preserved during updates. The new empty-body defaults are used when templates are first created; manually customized templates are never silently overwritten.

The release assets are built, validated, and attested through GitHub Actions.
