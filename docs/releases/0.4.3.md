Daylight brings a daily timeline, Kanban tasks, projects, and work-session tracking into one Obsidian view.
Everything is saved as ordinary Markdown notes in your vault.

### Review fixes in 0.4.3

- Remove the unused script-resource loaders that came with React DOM by using Preact's documented React compatibility layer. No vendor code is patched or disguised.
- Remove `!important` and `clip-path` from the plugin stylesheet while preserving scoped styling and accessible live announcements.
- Add release policy checks for runtime script creation, dynamic evaluation, and the reported CSS patterns.
- Build, validate, attest, and publish the release through GitHub Actions. Build-provenance attestations cover `main.js`, `manifest.json`, and `styles.css`.
- Attach only the files Obsidian downloads; checksums and dependency notices remain in the repository/build records, and the full Preact license is embedded in `main.js`.

### Install or update

Requires **Obsidian 1.8.7+**. Download `main.js`, `manifest.json`, and `styles.css` into your configured Obsidian folder's `plugins/daylight/` directory. Keep `data.json` when updating, then reload Daylight.
