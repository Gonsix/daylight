# Daylight icon studies

オレンジを基調にした、太陽モチーフのSVGアイコン案。日の出案を正式なプロジェクトアイコンとして採用し、README・Obsidianのビューとリボンに反映しています。

| 案 | ファイル | 意図 |
| --- | --- | --- |
| A・輪郭の太陽 | `sun-outline.svg` | 参考画像の丸い線と中央の輪を活かし、小さいUIでも軽やかに。 |
| B・塗りの太陽 | `sun-solid.svg` | 中央を塗り、ブランドマークとしての存在感を強める。 |
| C・日の出（採用） | `sunrise.svg` | 一日の計画を始めるDaylightを、水平線と朝日で表す。 |

共通仕様：背景透明、`viewBox="0 0 32 32"`、オレンジ `#F5A544`、線幅2.6、丸い線端。フォント・外部画像・外部参照を使いません。

`preview.svg` と `preview.svg.png` にダーク／ライト背景と16・20・24・32pxの比較を収録しています。プレビューの背景は比較用で、各アイコン自体は透明です。

UIのテーマ色に合わせる場合はSVG内の `#F5A544` を `currentColor` に変更できます。正式アセットは `../../images/daylight.svg`、Obsidian登録用は `../../../src/icon.ts` にあり、後者は同じ図形を100×100の座標系に変換しています。

採用案：`sunrise.svg`。5本の光線は太陽の中心 `(16, 22)` から放射状に30°間隔で配置し、中心からの距離12〜15を結ぶ長さ3に統一しました。`sunrise-preview.svg` と `sunrise-preview.svg.png` に調整後の単独プレビューを収録しています。
