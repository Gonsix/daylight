# 画面と操作

## 専用ビューと埋め込み

リボンまたは「Daylightを開く」コマンドから専用ビューを開く。起動時に開く設定と初期化は[起動](startup.md)を参照。Markdownコードブロック `daylight` または `vault-dashboard` でも同じ画面を埋め込める。`date: today` は当日、`date: YYYY-MM-DD` は指定日を表示し、不正な日付はエラーにする。日付を省略した場合、`daily_notes/01_daily/YYYY-MM-DD.md` に一致するノートはその日、それ以外は当日を使う。

## 絞り込みと詳細

タスクの表示範囲は選択日、進行中、予定日未定、すべて。選択日には当日の予定・実績に関連するものに加え、過去の未着手・進行中の繰り越しと当日完了したタスクも含む。「すべて」は完了・中止も含む。プロジェクト一覧には未完了・未中止・非アーカイブのものを表示し、件数は直接所属する未完了タスク数。プロジェクトを選ぶと関連する表示を絞り込む。

タスクとプロジェクトは詳細画面を開き、タスクのプロパティ編集やメモの追記を行える。予定は編集モーダルを開く。未送信のメモ下書きは同じビュー内で項目を切り替えても保持するが、ビューを閉じると消える。CommandまたはControlを押しながら項目を選ぶと、元ノートを背景タブで開く操作に対応する。

## キーボードとアクセシビリティ

対応フォームではCommand+Enterで送信する。通常のEnterは入力に使い、IME変換中、送信中やキーリピート等ではショートカットを実行しない。範囲選択はEnterで予定作成へ進み、Escapeで取り消せる。ローディング中は状態を支援技術へ通知し、背後の準備中の画面は操作できない。
