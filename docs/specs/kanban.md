# カンバンの並び順と親子関係

## 状態列と順序

未着手・進行中・完了を通常表示し、保留・中止は操作で表示する。不明な状態がある場合は別の列を作る。スマートフォンは列を縦に並べ、それ以外は横に並べる。

## タスクの並び替え

同じステータスのカラム内での順序はタスクのfrontmatterの整数 `sort_order` に保存し、状態ごとに全タスクで共有する。日付・プロジェクト等で表示を絞っても、別の順序は作らない。値の小さい順に表示し、同値または未設定では予定開始時刻、タイトル、パスを使って順序を決める。値のあるタスクは未設定より先に置く。

新規タスクや状態変更は移動先の末尾へ追加する。間隔の既定値は10000で、設定から1以上の整数に変更でき、既存値は変更されない。先頭への移動は先頭値から間隔を引き、末尾は末尾値に足し、間への移動は前後の整数の中間を使う。前後に整数の空きがない場合や安全な整数を超える場合はエラーにし、自動の再採番はしない。

対象列の順序未設定タスクは、その列で作成・並べ替え・状態変更による追加が行われると、既存の順序付きタスクの末尾から現在の表示順で採番する。複数ノートへの書き込みが発生する。絞り込み中の並べ替えでも、隠れたタスクを含む全体順序に挿入する。保存前に対象の状態・順序の変更を確認し、古い情報での上書きを拒否する。

## 親子関係とプロジェクト

タスクの `parent_task` に親ノートへのWikiリンクを保存する。親カードには直接の子だけを表示し、子自身のカードも元の状態列に残す。孫は直接の親カードに表示する。絞り込みで子カードが見えなくても、親カードの子一覧には全アイテムから取得した直接の子を表示する。

カード中央へのドロップやメニュー、詳細プロパティから親を設定する。自分自身、存在しないタスク、子孫を親にする指定や循環を拒否する。保存前にはメタデータでの検証に加えて、親のノート本文をたどって循環を確認する。親の変更は状態や作業実績を変更しない。プロジェクト変更もそのタスクの `project` を更新し、親子関係や作業実績を維持する。
