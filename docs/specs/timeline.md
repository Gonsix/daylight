# タイムラインと日付

## 表示対象

選択日のローカル0時から翌日のローカル0時に重なる予定・作業実績を表示する。予定はタスクと予定ノートの `schedule_start` と `schedule_end` が揃い、終了が開始より後の場合に対象になる。タスクの各作業セッションは予定と別枠で表示する。日またぎの範囲は選択日に含まれる部分に切り詰め、重なる枠は列に分ける。完了・保留・中止でもタイムラインから除外しない。

実行中の未終了セッションは現在時刻まで表示し、ダッシュボードは30秒ごとに現在時刻を更新する。日付やデータが変わったときに選択日に重なりうるアイテムを絞り、その結果を時刻更新時に再利用する。候補に実行中のセッションがなければ、時刻更新だけでは枠の再計算を行わない。日時が不完全な当日の予定や時間指定タスクは「日時の確認」に表示する。

## 範囲選択と予定作成

タイムラインの空白から作る範囲は30分単位で外側に丸め、最低30分とする。ハンドルで開始・終了を調整し、中央の移動では長さを保つ。選択範囲はその日の0〜24時に収める。選択後はボタンまたはEnterで予定作成画面を開く。IME変換中やドラッグ中、他の入力欄では選択確定を実行しない。

作成画面では1分単位の日時を入力でき、日またぎも可能。保存時の検証とノート形式は[ノートの作成・編集・削除](note-lifecycle.md)を参照。既存予定の時間ブロックをドラッグして日時変更する機能はない。

## 初期スクロールと日付

タイムラインの表示領域と内容の寸法が取得できるまで監視し、当日は現在時刻を可能な範囲で中央に置く。他の日は最初の枠の付近、枠がなければ9時付近に移動する。初期位置の設定後は監視を止め、手動スクロールを自動で戻さない。

日付選択には前日・翌日の移動と月カレンダーを使い、日付の検証は実在する年月日か確認する。ローカル日付の境界を使うため、UTC日付による単純な切り替えとは異なる。

**実装:** `src/model.ts`, `src/event.ts`, `src/TimeSelection.tsx`, `src/Daylight.tsx`, `src/DatePicker.tsx`。**主なテスト:** `tests/model.test.ts`, `tests/event.test.ts`, `tests/shortcuts.test.ts`。
